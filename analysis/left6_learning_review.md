# 左挥6学习失败分析

日期：2026-10-07。分析读取 gestures/6ea00a76-b715-4fc9-8804-2acdd018359a.json 及同 ID 草稿，在内存中复现。未修改个人记录、学习模型或程序逻辑。诊断脚本为 .scratch/analyze_left6.py，候选统计为 left6_learning_diagnostics.json，曲线为 left6_saved_demos.png。

## 直接原因

五个示范和三类约十秒记录齐全，三类质量校验全部有效。保存的 report 与当前算法复现一致：category=static，distance=0.3825604705，threshold=0.3223968504，候选轴为全六轴。

程序要求每类非目标的最近 DTW 距离大于 threshold / 0.72。本次需要超过 0.4477734033，实际只有 0.3825604705，故学习抛错，未产生可用模型。这是学习拒绝，并非文件写入失败。示范和校准已保存，model=null。

六轴不是已经选定的有效轴，而是失败报告记录的最后一组候选。63 个候选组合中，62 个在静止距离检查时被拒绝；剩余 gx 在普通晃动检查被拒绝：距离 0.3081707592，要求超过 0.3115391494。算法未继续检查这些候选的完整识别行为。

## 学习规则与实际识别的差异

对被拒绝的六轴候选模型直接执行完整识别：静止、普通晃动、拿放三段校准均零事件；对五段示范分别流式回放，各产生一个事件。静止窗口进入 model.match 时也被“有效运动不足”拒绝。

因此原始 DTW 距离余量不是此数据上实际静止误触发的证据；当前学习前置判定没有结合实际运动拒绝条件，存在过度拒绝。该结果只针对训练与校准记录，不能证明新目标或独立非目标的识别率，也不能直接批准该候选为正式模型。

仅选 gz 的候选在拿放记录产生一次事件，区间为 0.634～2.917 秒。仍有实际混淆风险，不能直接固定 gz 或简单放宽全体门槛。

幅度、波形和前后静止比例有差异。六轴留一最近示范距离的最大值 0.2277013707 来自第 4 次，按 positive * 1.35 + 0.015 推出阈值 0.3223968504。不能只凭时长或峰值判定某次错误。

第 3、5 次尾段较长。范围建议使用未平滑的加速度差分除以采样间隔，尾段加速度变化仍超出运动阈值：第 3 次最后检测时刻 4.266 秒、第 5 次 5.237 秒；相应陀螺活动低于阈值，最后检测由加速度差分驱动。这解释了建议范围为什么接近整个原始录制。小幅抖动/噪声被延伸为运动的可能性较大，需结合原始动作核对，而非声称传感器损坏。

仅在内存把第 3、5 次结束点改到 2.947、3.066 秒后，学习仍拒绝：静止距离 0.3961457459，阈值 0.3338495085。进一步按明显转动范围试裁五个示范也仍拒绝。因此无法保证用户仅重新点范围即可解决；试裁没有保存，不能把诊断边界当作人工确认结果。

## 后续修正方向

学习时需要结合运动、结束、边界与完整流式事件的实际拒绝行为评估负例，保留独立验收和保守要求；范围建议需要平滑、噪声依据和持续运动判断，避免单个加速度差分不断拉长尾段。补强波形幅度一致性和可定位报告，说明失败候选及真正阻断条件。

现有静止记录通过质量检查，重录静止不是当前证据支持的优先解法。任何算法修改之后，仍须使用独立十次目标和三类各三十秒的新记录验收，不以现有训练回放代替。
