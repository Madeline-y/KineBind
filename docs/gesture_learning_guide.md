# 手势学习、诊断与独立验收

日期：2026-10-07。

## 启动与旧手势

在项目目录使用现有 kinebind 环境：

```powershell
conda activate kinebind
python gesture_app.py --dry-run
```

测试模式仍使用真实传感器输入，识别后只记录模拟鼠标请求。实际使用时去掉 `--dry-run`；加载手势不会自动开始控制，必须点击“开始识别”。顶栏“停止识别 / 学习”始终可用。左侧控件可滚动。

旧手势可以直接加载并按旧规则使用，界面显示“旧规则”。新规则学习需要五个确认示范及三类校准；旧的单段非目标记录不会自动替代三类记录。原始示范和绑定可以复用。

## 复用“左挥2”或录入新动作

1. 加载“左挥2”，依次选择五个示范检查原始曲线；也可以新建手势，倒计时后每次录一个完整动作，手动结束。
2. 新录制或导入的数据会自动显示建议范围。已有示范保持保存过的边界；需要调整时点击“重新建议当前范围（仍需确认）”。
3. 检查建议包含全部动作阶段，手动调整起止点，点击“确认保存这次示范”。左挥要包含左挥和回收，动作内部停顿应保留。建议存在歧义时由你检查，不会自动保存。
4. 从类别列表分别选择“静止”“普通晃动”“拿放”。每类倒计时后采集约十秒自动结束，也可导入明确属于该类的连续 CSV。工程时间容差为至少 9.5 秒。
5. 静止时保持示范起始握姿；普通晃动时做日常小幅活动；拿放时正常拿起、放下设备。避免在非目标录制里重复完整目标动作。活动类别如果几乎静止会要求补录。
6. 左挥点击“单加速度轴学习并保存（左挥）”。程序只尝试 ax、ay、az 的单轴候选，最终只保存一个加速度轴用于匹配、运动与结束判断，不回退到陀螺仪或多轴。其他动作如需通用流程，使用“自动选轴学习并保存（其他动作）”。两种入口都用完整流式识别检查三类校准记录必须零事件。
7. 查看有效轴、接受阈值和学习报告。不能区分时不会保存可用新模型；报告会定位相关示范、类别或时间片段。“检查 / 补录相关数据”可以返回相应入口。

有效轴不是固定物理左右；握持朝向改变会影响信号。接受距离表示波形差异阈值，不是厘米或概率。保持同一只手、相近握法与起始朝向，允许自然快慢变化。

单加速度轴入口先用实际识别的时长、有效运动、结束及边界条件检查非目标窗口，再对仍可能参与匹配的窗口要求 DTW 安全余量。被这些条件明确拒绝的片段不会仅因距离余量不足阻止学习；所有原始校准仍须完整回放零事件。这不是直接放宽接受阈值。六轴原始采集格式继续兼容，单轴模型实际识别仅使用保存的一个加速度轴。

重新学习失败时，磁盘上原有可用模型保留。点击“加载”恢复已保存模型；点击“恢复未学习草稿”恢复改过的示范、分类记录及失败报告。修改示范或校准后，草稿需要重新学习。

## 保存实时测试数据

点击“开始识别”后，程序自动把这一轮实时输入写入项目 `recordings` 目录中的 `realtime_test_日期_时间_编号.csv`。测试模式 `--dry-run` 同样保存实际设备数据。界面及日志显示本次文件路径；点击停止、断开设备、切换手势或关闭窗口时完成保存，并显示记录条数。每轮使用新文件，不覆盖上一轮。

CSV 保留设备原始时间戳、序号、原始六轴、从本轮第一条记录开始的相对时间、量程与手势标识。单加速度模型的识别规则保持不变。保存的是整轮有效输入，不限于曲线最近的 600 条，也包括未被识别的动作。可通过现有“回放 CSV”入口查看，或将文件路径交给我分析。录入示范、学习与 CSV 回放不会创建实时测试文件。

数据每秒刷新到文件，正常停止/断开/关闭会关闭文件并写入剩余缓冲。保存出现错误时停止控制并报告错误。没有收到数据时可能只有 CSV 表头；这不代表已录到动作。本功能开始前的历史测试无法恢复。

## 独立验收

冻结待验收模型后另采数据。十次新完整目标动作至少九次正确、各一次事件；提前或重复触发单独判失败。静止、普通晃动、拿放另各采三十秒，三类事件及模拟执行请求都必须为零。

可以用采集器记录一个包含十次动作和间隔静止的连续目标 CSV，再单独记录三类非目标。使用设备相对时间在曲线上人工确认十个目标起止区间。

复制项目根目录的 `acceptance_manifest.example.json` 为自己的验收清单。示例默认是未完成状态，不会声称已经通过。清单路径相对于清单所在目录。

清单需要填入：

- `profile`：已经学好的新规则手势 JSON。
- `independent`：确认数据未用于学习、选轴或调参后设为 `true`。
- `target`：包含 `csv` 路径，以及十个 `[起点秒数, 终点秒数]` 的 `intervals`，按时间排序、不重叠。
- `non_target`：`static`、`shake`、`pick_place` 分别指向新采的三十秒 CSV。

```powershell
python verify_gestures.py --manifest acceptance_manifest.json --output acceptance_report.json
```

报告记录模型和数据指纹、逐次正确/漏识别/提前/重复、背景事件、模拟执行请求及匹配距离。动作结束标注容差为 0.08 秒，按区间评分而不是只数总事件。报告输出文件已存在时不会覆盖，请选择新文件名。

退出码：0 为真实独立回放指标通过；1 为失败；2 为缺数据、清单错误或仅合成数据检查。合成数据只验证软件流程，报告不会设为真实通过。工具会检查已知训练片段重用，但无法代替你确认数据确实未用于调参。

调参后重新正式验收应另采新记录。回放报告使用模拟鼠标；真实指针行为还需你主动开启识别，核对实际移动以及停止后不执行。每个手势分别验收。

## 软件验证

```powershell
python -m unittest discover -s tests -v
python -m mypy kinebind gesture_app.py verify_gestures.py --ignore-missing-imports
python gesture_app.py --smoke-test
```

隐藏窗口检查使用临时存储、合成示范和模拟鼠标，不修改个人手势、连接设备或移动真实鼠标。程序没有要求替换固件或安装新依赖。默认 Python 如果与 matplotlib 不兼容，请使用 kinebind 环境。
