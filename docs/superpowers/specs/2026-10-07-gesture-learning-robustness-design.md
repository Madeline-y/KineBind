# KineBind：通用手势学习与保守识别改进规格

日期：2026-10-07。根据本轮需求确认编写。程序实现与软件验证已完成，独立实录验收待完成。用户明确要求交付本地规格，并已确认复用现有应用控制器的测试边界。

实施结果见 [操作说明](../../gesture_learning_guide.md) 和 [验证记录](../../gesture_learning_validation.md)。57 项自动测试、类型检查及隐藏窗口检查通过；这些检查使用合成数据，不能证明真实 9/10 和三类零误触发指标。

本文更新第一版中固定六轴匹配、自由录制单段非目标数据和完全手动选取样本边界的设计。原有设备采集、完整动作定义、显式启停、单次执行和鼠标绑定要求继续适用。本文的独立数据验收门槛取代旧规格中未确认的识别率说明。

## Problem Statement

用户已能录入自己的动作、保存五个示范，并学习和使用鼠标绑定。但在录入“左挥2”后，程序提示“示范与非目标动作区分不佳，请重录；不要在非目标录制中重复目标组合”。实际检查发现，这段非目标记录几乎静止，用户没有明显重复目标组合；当前匹配方法仍会把一些静止片段判得过于接近示范。

现有学习流程固定比较全部六轴，依据示范间差异计算阈值，再检查单段非目标记录是否保留足够距离。它没有充分解决无效轴、过长静止、静态姿态差异和真正运动结构之间的关系。失败提示也不能帮助用户确定该调整边界、重录某个示范，还是补充某类非目标记录。

用户需要改进通用自定义手势流程，而不是为左挥单独编写识别规则。不同手势可以具有不同的有效轴；识别优先避免误触发，允许少量漏识别。使用范围为同一只手、相近握法和起始朝向，允许自然快慢变化。

## Solution

用户继续录入并确认五次完整示范。录制结束后，程序在六轴曲线上建议动作起止范围，用户检查、调整并确认保存。建议范围去掉动作前后的多余静止，保留动作内部停顿；左挥仍定义为“向左挥动 → 向右回收”的完整组合。

非目标校准分为静止、普通晃动、拿放三类，每类引导采集约十秒。程序检查类别是否齐全、记录质量和实际活动，并允许单独补录某类数据。

学习时，根据示范的重复性和与三类非目标的区分度选择有效轴，允许单轴或多轴。所选轴用于受约束的 DTW 波形匹配，并结合有效运动、完整结束和单次事件判断。无法找到可靠区分条件时，程序保守地拒绝学习，并给出具体依据。

学习完成后显示有效轴、接受距离阈值和各类非目标校准摘要。用户主动开始识别后，每个完整动作最多执行一次绑定；停止后不再执行。旧手势文件仍可加载，已有原始示范可复用于新规则学习。

最终验收使用独立新数据：十次完整目标动作至少正确识别九次；另采静止、普通晃动、拿放各三十秒，三类均不得触发指令。

## User Stories

1. 作为用户，我希望不同手势使用同一学习流程，以便增加新动作时无需修改识别代码。
2. 作为用户，我希望继续为动作命名，以便按自己的动作定义管理手势。
3. 作为用户，我希望每个手势保留五个独立示范，以便学习反映自然重复中的差异。
4. 作为用户，我希望录制前保留倒计时，以便准备握姿和动作。
5. 作为用户，我希望手动结束示范录制，以便完整保留动作结束阶段。
6. 作为用户，我希望录制后看到建议起止点，以便减少手动寻找边界的工作。
7. 作为用户，我希望建议范围显示在六轴曲线上，以便检查程序是否找到了真正动作。
8. 作为用户，我希望手动调整建议范围，以便修正过早开始或过早结束的建议。
9. 作为用户，我希望确认后才保存建议范围，以便程序不会未经检查修改训练样本。
10. 作为用户，我希望保留原始完整录制，以便调整边界后仍能恢复和检查。
11. 作为用户，我希望动作前后长时间静止被排除，以便模板突出动作本身。
12. 作为用户，我希望动作内部停顿被保留，以便自然的组合动作不会被拆开。
13. 作为用户，我希望左挥与回收一起保存，以便一次往返对应一个手势。
14. 作为用户，我希望范围存在歧义时得到提示，以便自己确认而不是使用错误边界。
15. 作为用户，我希望单独重录某个示范，以便不必重新录入全部动作。
16. 作为用户，我希望单独采集静止数据，以便检查静止是否会被误认为目标动作。
17. 作为用户，我希望单独采集普通晃动，以便校准日常小动作的误触发风险。
18. 作为用户，我希望单独采集拿放活动，以便拿起、放下和正常持握调整不会触发绑定。
19. 作为用户，我希望看到每类采集的说明和进度，以便明确当前应该做什么。
20. 作为用户，我希望每类校准约十秒，以便完成三类校准时保持约三十秒的总采集量。
21. 作为用户，我希望看到缺少或无效的类别，以便有针对性地补录。
22. 作为用户，我希望只重录需要改进的类别，以便保留其他有效记录。
23. 作为用户，我希望普通晃动和拿放记录不能被纯静止替代，以便校准确实覆盖非目标活动。
24. 作为用户，我希望避免把目标动作标成非目标，以便训练标签不互相矛盾。
25. 作为用户，我希望程序自动选择有效轴，以便不必理解传感器坐标后才能学习。
26. 作为用户，我希望不同手势允许选择不同轴，以便相同流程适应不同运动方式。
27. 作为用户，我希望可以选择多个有效轴，以便必要的辅助信息不会被强制丢弃。
28. 作为用户，我希望轴选择考虑重复性和区分度，以便波动最大的轴不被盲目采用。
29. 作为用户，我希望看到最终选择的轴，以便理解程序在比较哪些数据。
30. 作为用户，我希望看到接受距离的含义，以便知道它是差异阈值而不是距离单位或准确率。
31. 作为用户，我希望看到最容易混淆的非目标类别，以便知道校准的薄弱环节。
32. 作为用户，我希望失败时获得具体示范或类别的信息，以便决定调整边界、重录或补录。
33. 作为用户，我希望静止姿态差异不会被当作识别动作的主要证据，以便同一姿态下的静止也能被拒绝。
34. 作为用户，我希望保守地拒绝模糊动作，以便优先减少鼠标误触发。
35. 作为用户，我希望自然快慢变化能够被识别，以便不必每次以机械一致的速度做动作。
36. 作为用户，我希望仅完成动作的一部分不触发，以便左挥前半段或单独回收不会执行指令。
37. 作为用户，我希望每个完整动作最多触发一次，以便连续窗口不会重复执行绑定。
38. 作为用户，我希望再次完整做动作可以再次触发，以便独立动作不会被错误地合并。
39. 作为用户，我希望主动开始识别才执行指令，以便录入和检查时鼠标不受影响。
40. 作为用户，我希望停止或断开设备后不执行旧事件，以便保持启停行为可靠。
41. 作为用户，我希望失败学习不覆盖已保存的可用模型，以便原有手势仍可恢复使用。
42. 作为用户，我希望重启后恢复有效轴、模板和校准结果，以便识别行为不会因重启改变。
43. 作为用户，我希望旧手势文件仍能加载，以便已有数据不因格式升级而丢失。
44. 作为用户，我希望复用原始示范进行重新学习，以便采用新规则时减少重复录制。
45. 作为用户，我希望十次独立新动作至少正确识别九次，以便学习结果具有实际可用性。
46. 作为用户，我希望三类独立非目标测试均不触发，以便验收符合优先防止误触发的要求。
47. 作为用户，我希望识别结果和执行结果分别可见，以便区分动作漏识别与鼠标执行失败。

## Implementation Decisions

- **通用流程与使用条件。** 使用现有六轴采集协议、单位、设备时间戳和量程校验。学习、回放和实时识别采用同一处理版本。按手势独立学习和选择使用；轴选择不依赖手势名称，也不把某个轴的正负直接解释为物理左右。
- **复用现有模块边界。** 在应用控制器中编排范围建议、三类校准、学习状态、诊断和识别会话；扩展示范及手势数据、匹配与识别、持久化和窗口展示职责。识别继续输出事件，由现有执行门处理鼠标绑定；不引入第二套执行通道。
- **范围建议与确认。** 根据六轴运动变化提出有限候选范围，并在曲线上预览。边界建议在新录制或导入记录的检查阶段生成。静止、多个独立动作、缺口或截断导致不确定时，显示原因并允许人工选取或重录。用户确认前不生成已确认示范；重新查看已有示范不能自动覆盖已保存边界。
- **完整组合。** 建议范围和识别都以用户示范的完整过程为依据，不把内部短暂停顿直接当作动作结束。左挥要包含左挥与回收；其他手势不强制具有往返结构。动作前半段、单独回收及长静止不作为完整左挥接受。
- **分类校准。** 为静止、普通晃动、拿放分别保存带类别的原始记录和质量结果。每类目标约十秒，由界面显示倒计时、采集进度和完成状态。类别之间分别计时与评估，不能拼接成带有虚假时间跳变的连续记录。允许按类别重录或导入有明确类别的记录。
- **校准质量。** 检查采样连续性、量程、时长和有效数值。静止类必须足够稳定，作为噪声和陀螺仪零偏估计的依据，不能从混合活动记录估计零偏。普通晃动与拿放必须包含相对于静止噪声可辨认的活动，单纯静止不能冒充这两类。活动较强不直接视为质量更好；明显削顶、目标与非目标标签疑似冲突或类别不足时，提示具体问题并阻止新模型标为可用。
- **有效轴选择。** 候选可以包含加速度轴、角速度轴或二者组合。评估示范间一致性以及与每类非目标的区分程度，不能根据单次峰值、总方差最大或与自身匹配的零距离直接决定。优先满足保守的区分条件，再优先使用较少轴；需要多个轴时允许保留多个，必要时可使用全部六轴。计算在后台进行，并报告进度。
- **防止静态姿态捷径。** 轴有效性和运动条件必须基于时序运动变化；不能仅因为示范与背景的加速度静态基线不同就认定动作可区分。须在接近示范起始朝向的静止数据上检查拒绝行为。用于运动检测的信号可以与 DTW 匹配轴集合不同，但都必须随模型保存并可复现。
- **一致的距离定义。** 保留固定物理尺度与幅度信息，并采用受约束的时间对齐。有效轴数量改变时，距离归一化和阈值必须共同调整，避免仅靠减少维度获得虚假的更小距离。DTW 的时间变形限制、平滑、重采样、轴集合及缩放参数随模型持久化；回放与实时路径不得各用一套规则。
- **阈值与完整匹配条件。** 接受阈值同时参考不同示范间的距离和三类非目标候选距离，保留拒绝余量，不单纯放宽阈值使学习通过。运动成立、时长、完整波形、结束特征和距离条件一起决定接受。没有可行区分条件时拒绝新模型，输出诊断。运动开始和结束条件依据示范及静止噪声校准，不把纯平移手势强制限定为必须有明显转动。
- **最终事件校准。** 背景检查不仅比较固定窗口的 DTW 距离，还须通过拟保存模型的完整流式识别路径回放三类校准数据，确认没有接受事件。固定窗口通过不等于流式识别通过；训练记录无事件也不替代独立验收。
- **可解释结果。** 成功结果包含有效轴、阈值、各类非目标摘要和最易混淆类别。失败结果可指出异常示范编号、边界疑点、缺失类别及混淆片段，给出对应操作。采样或边界问题不能笼统归因于用户重复目标动作。匹配距离是差异量，不显示为概率、厘米数或识别准确率。
- **状态与失效。** 修改已确认示范或任一校准类别使新模型草稿需要重新学习。学习基于数据快照；运行中数据被修改时不得保存过期结果。未学习或校准不全的新手势不能启动实时控制。录入、检查、学习、停止、断开和错误状态均不允许执行绑定。
- **兼容与存储。** 为新模型及分类校准增加明确版本，保存原始记录、用户确认边界、有效轴、处理参数、各类质量与校准报告、模板及绑定。旧格式按旧处理语义加载，不能静默套用新算法或宣称已通过新验收。使用新规则需要重新学习；旧原始示范可复用，旧无类别背景需人工分类或补采三类记录。
- **保存保护。** 继续采用校验后原子保存。重新学习失败或数据被修改时保留原有可用模型；新草稿和失败报告不能把原模型覆盖为不可用。名称、手势 ID、绑定与原始记录的归属保持明确，损坏文件不能影响其他手势加载。
- **实时与执行约束。** 有界候选窗口和明确运动开始条件避免把长静止作为动作候选。消费已接受动作区间并按会话及事件去重，不能仅用固定冷却时间。完整动作结束条件成立后及时产生事件，不额外强制等待固定半秒；记录延迟。停止使会话失效并丢弃待执行事件，设备重连后需主动开始。

## Testing Decisions

### 主要测试边界

复用现有应用控制器这一高层边界：输入录入、确认、分类采集、学习、加载、回放和启停命令，以及六轴样本；观察可见状态、学习报告、识别事件、模拟鼠标请求和保存后重新加载的行为。复用现有可替换采样源、确定性回放及鼠标替身，不为每个内部算法增加专用测试接口。

现有先例包括应用启停和重载默认停用、学习失败保留旧模型、手势切换隔离旧会话、存储损坏隔离及完整动作单次事件测试。新增自动测试以这些外部行为为依据，不检查特定 DTW 路径、循环次数或必须选中某一个轴。

上述测试边界已经用户明确确认，用于验证本轮约定的验收行为。

### 自动验证行为

1. 五个独立示范可走完录制、建议范围、人工调整、确认及重录流程；原始数据可恢复，未确认建议不替换训练样本。
2. 前后静止较长的录制可以提出覆盖完整动作的建议；内部停顿不造成半动作被接受。纯静止、多个动作或截断录制不能被无提示地自动确认。
3. 三类校准的状态、记录和质量分开保存；单独补录一类不丢失其他类别。缺少类别、无效采样及静止冒充活动类别不能生成可用新模型。
4. 在有效信号分别位于不同轴的动作上使用同一学习流程，不依赖手势名称；无信息轴或姿态基线差异不能成为可靠识别的唯一依据。
5. 单轴和多轴模型均能保存、加载及回放，轴数量改变不会破坏距离和阈值的一致性。测试结果针对接受或拒绝行为，不要求某个固定轴集合。
6. 使用模型完整流式路径拒绝静止、普通晃动、拿放；对相同起始姿态的静止专门验证，避免仅因姿态不同而通过校准。
7. 完整左挥和回收只产生一次事件；前半段、单独回收、内部停顿处及重叠窗口不额外触发，下一次独立完整动作可再次识别。
8. 区分不足时报告相关示范或非目标类别及可操作建议，不能只返回泛化的重录提示。失败报告和成功报告不能混用。
9. 修改示范或校准后需要重新学习；失败学习或快照失效不覆盖旧可用模型。重载新模型后匹配及拒绝行为一致，旧模型按旧版本语义加载。
10. 显式启停、断开、量程不符、时间异常和旧会话待执行事件继续满足原有控制约束；自动测试使用鼠标替身。
11. 新模型校准不足或学习失败不能启动控制；运行中的窗口仍能响应停止和断开操作。

### 独立实录验收

- **前提。** 冻结待验收的模型和参数。采集使用同一只手、相近握法和起始朝向，包含自然快慢变化；目标动作边界经人工确认。学习数据、选轴数据和校准记录不能兼作最终验收数据。
- **目标识别。** 新录制十次独立完整目标动作，至少九次各产生一个有效识别事件。任何提前触发或对同一次动作重复触发均单独记为失败，不能靠总事件数达到九次来通过。
- **非目标拒绝。** 另采静止、普通晃动、拿放各三十秒，以完整实时或等价流式回放路径测试；每类接受事件和绑定执行请求都必须为零。
- **执行核对。** 用模拟鼠标请求验证识别到绑定的完整链路，记录漏识别、误触发、提前触发、重复触发、匹配距离及检测延迟。另由用户主动开启实板控制核对实际鼠标行为，识别正确与执行失败分别记录。
- **数据独立性。** 验收失败后可以根据问题改进算法或数据，但再次正式验收使用另一套独立新记录；不能把已经用于调参的数据继续标为未见过的验收集。
- **通用性检查。** 自动验证至少覆盖有效轴不同的动作。真实识别率门槛按被验收的手势分别计算；“左挥2”通过不代表所有未来手势已通过。

## Out of Scope

- 针对手势名称“左挥”硬编码固定传感器轴、峰值正负顺序或专用识别分支。
- 任意换手、任意握持朝向或大幅改变握法后的识别保证。
- 神经网络训练、TinyML、板端识别、BLE 和固件改造。
- 同时分类多个已学习手势及其冲突仲裁。
- 无需用户确认的自动保存示范、全自动结束示范录制，以及自动改写旧训练边界。
- 新增鼠标点击、拖拽、连续空中鼠标、键盘绑定或按前台软件切换指令。
- 系统后台自动开启识别、开机启动及常驻服务。
- 为保证学习成功而取消非目标拒绝条件或直接扩大接受阈值。
- 将这次有限时长的零误触发验收解释为长期绝不会误触发的保证。
