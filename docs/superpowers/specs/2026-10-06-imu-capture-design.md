# IMU 采集设计

用户已确认 COM7、kinebind 环境，并要求直接创建文件。本次范围是 50 Hz 六轴输出、实时曲线和 CSV 保存。

采用新固件输出带设备时间戳与序号的单行 CSV，而非解析旧示例的多行文字。
保留旧输出的识别错误提示，避免误以为串口已连通就代表正确采样。
仅解析旧输出可以减少上传操作，但约 1 Hz 无法支持当前采样目标；完整桌面应用则超出当前范围。

- firmware/imu_stream/imu_stream.ino：Seeed mbed 2.9.3，LSM6DS3 2.0.7，目标输出 50 Hz。
- imu_protocol.py：八列协议、ASCII 分片、有限数值、设备时间戳与序号处理。
- capture_imu.py：默认 COM7/115200，串口读取线程负责全部 CSV；主线程显示两组曲线。
- Python 3.11；依赖 pyserial、matplotlib，环境同时保留 numpy/scipy 供后续数据处理。
- 传感器刷新 104 Hz，加速度 ±4 g，角速度 ±500 deg/s；不做动作识别、滤波或校准。
- 10 秒无有效记录则停止并提示；不覆盖已有文件；设备重启终止当前记录。
- 默认输出 recordings，文件名和接收时间使用 UTC+08:00，模拟数据明确标识。

验收：协议与 CSV 的自动测试通过；模拟录制接近 50 Hz；真实目标板编译通过。
板端上传及真实实时采样作为硬件验收，未完成时明确报告。
