## 尚未验收

需要重新学习后的真实新模型、十次独立完整目标动作的人工确认区间，以及静止/普通晃动/拿放各三十秒的新 CSV。随后使用 `verify_gestures.py` 生成逐次结果、距离、延迟、模型/数据指纹、三类事件及模拟执行请求统计。必须达到至少九次正确、无提前/重复/区间外事件、三类各零事件与零请求。

合成检查只验证软件流程。已有训练记录不能用作独立验收，调参后需另一套独立数据；真实设备与鼠标启停行为仍需用户主动操作核对。因此 05 保持待验收，当前不声称真实指标已达标。

目录没有 Git 仓库，无法遵循 implement 的当前分支提交要求；改动保存在工作区，没有初始化仓库。使用方式见 [操作说明](gesture_learning_guide.md)。

2026-10-07 按用户要求只新增实时测试数据保存。窗口点击开始识别后，每个实时会话单独写入 recordings/realtime_test_日期_时间_编号.csv；保存设备原始时间戳、序号、六轴、相对会话时间、量程及手势标识。停止、断开、切换、错误及关闭沿现有 stop 边界完成关闭，界面显示文件路径和条数。CSV 可用原有回放入口读取，非默认量程从列中恢复；没有修改学习或匹配算法。
