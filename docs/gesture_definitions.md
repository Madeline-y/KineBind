# 手势定义

手势由用户定义。采集、标注、模板和识别统一采用下面的动作范围。

## 左挥（left_swipe）

- 完整动作：向左挥动 → 向右回收到起始位置。
- 一次完整往返算一次“左挥”；回收阶段属于同一个手势。
- 样本起点：开始向左挥动之前。
- 样本终点：向右回收完成、动作结束之后。
- 保留两个阶段之间实际发生的停顿；动作前后的长时间静止不属于手势主体。
- 快慢可以不同，比较模板时需要考虑持续时间差异。
- 左右按用户的实际动作理解；传感器轴的正负号随握持朝向变化，不能直接当作物理左右。
